# 段6 ①の直し（区間の行き止まり・ファイルが消えるおそれ）設計書

## なぜ
段6①の最終確認で、公開前に直したほうがよい2点が残った。
1. 区間は1曲5つまでだが、消す方法が無い。保存した区間の端を動かすと黙って「保存していない区間」になる。
2. 一覧を開くたびに「記録に無い曲のファイルを消す」掃除が動く。記録（localStorage）だけが消えたときに、曲のファイルまで消えてしまう。

## やること
### ① 区間
- 保存した区間を選んでいるとき「区間を 消す」ボタンを出す。「消しますか？」と確かめてから消す（`removeSection`）。
- 保存した区間の端を動かしたら「まだ 保存して いません」と出し、ボタンを2つ出す。
  - 「上書きする」：同じ id のまま、区間の範囲を新しくする。前回の線と前回の合いぐあいは消える。「前回の 線と 合いぐあいは 消えます。上書きしますか？」と確かめる。
  - 「新しい 区間として 保存」：今までどおり（5つのときは上限の案内）。
- 5つあって保存できないときの文を「保存できる 区間は 5つ までです。いらない 区間を 消すと 保存できます」にする。

### ② ファイルの掃除
- 一覧を開いたときの自動の掃除（`removeOrphans`）をやめる。
- ファイルを消すのは次のときだけ。
  - 曲を消したとき（今までどおり）
  - 曲の追加に失敗したとき（今までどおり）
  - バックアップを読み込んだとき：読み込む前に「このスマホの 曲で、バックアップに 無い ものは 消えます。読み込みますか？」と確かめ、「はい」のときだけ、読み込んだあとの記録に無い曲のファイルを消す。

## やらないこと
- 区間の名前を変える機能
- 前回の線を残したまま範囲だけ変える（時間の基準がずれるため）

## 確かめ方（テスト）
- 区間を5つ保存 → 1つ消す → 新しい区間を保存できる。消すのは確認のあとだけ
- 保存した区間の端を動かすと「まだ 保存して いません」。上書きすると範囲が変わり、前回の線と合いぐあいが消える
- 記録が空でも、一覧を開いただけではファイルが消えない
- バックアップの読み込み：確認で「いいえ」なら何も変わらない。「はい」なら、記録に無い曲のファイルだけが消える
- 新しい文に禁止の言葉が無い

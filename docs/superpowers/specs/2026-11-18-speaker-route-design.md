# マイク使用中のお手本の音を大きくする（小さな直し）設計書

- 作成日：2026-11-18
- 状態：持ち主の OK 済み（2026-11-18）

## なぜ
持ち主の iPhone で、マイクを使う段（段2〜5）のお手本の音が小さい。段1（マイクなし）は普通。イヤホンでは大きく聞こえる。
原因：マイク使用中は音の出し方が「マイクと再生（play-and-record）」になり、iPhone が耳元のスピーカーから鳴らす。

## 実機の実験の結果（持ち主の iPhone・Safari、`public/audio-test.html`）
| 候補 | 音 | マイク |
|---|---|---|
| いまのまま | 普通 | ○ |
| A：鳴らす間だけ「再生だけ（playback）」にし、鳴り終わったら戻す | 大 | ○ |
| B：マイクを閉じて開き直す | 大 | ◎ |
| C：先に play-and-record を指定 | 少し小 | ○ |
| D：音だけ3倍 | 大 | ◎ |
| E：audio 要素で鳴らす（段4の自分の声の聞き直しと同じ） | 小 | ○ |

## えらんだ方法：A
- B は、ホーム画面のアプリで毎回マイクの許可を聞かれるおそれがある
- D は耳元のスピーカーのまま大きくするだけで、耳に近いと大きすぎるおそれがある

## やること
- 音を鳴らしている間だけ `navigator.audioSession.type` を `'playback'` にし、鳴り終わったら、マイクが開いていれば `'play-and-record'` に戻す
- 対象：お手本の音（段1〜5のすべての `playNote`）と、段4の「自分の 声」「続けて 聞く」の聞き直し（audio 要素）
- 切りかえの仕組みは `src/audio/tone.js` の1か所にまとめる（次の版の YouTube の再生でも使うため）
- 音が続けて鳴るとき（段5のメロディなど）に切りかえがばたつかないよう、戻すのは鳴り終わって少し（200ミリ秒）待ってから
- 実験ページ `public/audio-test.html` は消す

## やらないこと
- 音量そのものは変えない（耳を痛めないため）
- `navigator.audioSession` が無い端末（iPhone 以外など）では何もしない

## 気をつけること
- 歌っている間（判定・録音の間）は必ず `'play-and-record'` に戻っていること。段4はお手本のあと 500ミリ秒待ってから判定するので、200ミリ秒あとに戻せば間に合う
- マイクを閉じたあとは `'play-and-record'` に戻さない
- 確かめたのは Safari。ホーム画面のアプリでも同じかは、実機の確かめ表に1行足して確かめる

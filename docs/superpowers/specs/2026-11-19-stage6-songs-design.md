# 段6「好きな曲で練習」設計書

- 作成日：2026-11-19
- 状態：下書き（持ち主の答えを反映。設計書の OK 待ち）
- 前の設計書：`docs/superpowers/specs/2026-11-18-karaoke-trainer-design.md`（7章の段6）

## 1. なぜ作るのか

持ち主は、カラオケで好きな曲（RADWIMPS、優里「ビリミリオン」、ケツメイシ、GReeeeN）を歌えるようになりたい。段1〜5で音程の土台を練習したあと、本番の曲で練習する場所がほしい。

持ち主の言葉：
- 「何か視覚的に合っているか確認できるとよい」
- 「YouTube も利用はしたい」
- iPhone の「ミュージック」に入っている曲は**買った曲**

## 2. ゴール

- 好きな曲の1フレーズを、くり返し・ゆっくり練習できる
- **買った曲**では、歌手のお手本の線と自分の声の線を重ねて、合っているかを目で見られる
- **YouTube** では、曲を流しながら自分の声の線（ゆれ・前回との比較・声の地図からはみ出していないか）を見られる
- 本番の答え合わせは、公式のカラオケアプリ（分析採点JOYSOUND・カラオケ@DAM など）やカラオケ店の採点で行う、と案内する

## 3. やらないこと

- YouTube などから曲や音を保存する（YouTube の規約で禁止。違法アップロードと知りながらのダウンロードは、個人で使うだけでも違法）
- iPhone の「ミュージック」アプリの中を直接読む（ブラウザから作ったアプリにはできない）
- Apple Music（聞き放題）の曲を使う（鍵がかかっていて読めない）
- アプリの中で歌声と伴奏を分ける（iPhone では重すぎる）。サーバーも使わない
- YouTube の曲のキー（高さ）を変える（埋め込みの音はアプリから触れないため。YouTube はキーの案内だけ）
- 曲のデータや歌声だけのファイルを、人に渡す・ネットに上げる仕組み

## 4. 失敗と言えること

- お手本の線を「正しい答え」と言い切る（伴奏がまざった線や、分けたファイルの線にもずれはある。「目安」と書く）
- 曲の高い所で、のどに無理をさせる練習になる（声の地図からはみ出す所は先に知らせ、キーを下げる案内を出す）
- 曲のファイルや声がスマホの外に出る
- 責める言葉・点数で落ちこませる表示

## 5. 決まっている条件

- 作り方はこれまでと同じ（Vite の Web アプリ。iPhone の Safari とホーム画面のアプリ）
- 曲のファイルと、そこから作ったお手本の線は**スマホの中だけ**に保存する
- 録った声は保存しない。保存してよいのは自分の声の**高さの数字の並び**（前回との比較のため）だけ
- 段6だけは YouTube を使うときに電波が必要。買った曲の練習は、一度読み込めば電波なしで動く
- YouTube を使うとき、YouTube のプレーヤー（外のプログラム）を読み込む。これまでの「外のファイルを読み込まない」の**例外は段6の YouTube だけ**。プライバシーのため `youtube-nocookie.com` の埋め込みを使う
- 曲に合わせて歌うときは**イヤホンが必要**（スピーカーだと、曲の音をマイクが拾う）
- 言葉の決まりは `CLAUDE.md` のとおり

## 6. 作り方の候補（えらんだ理由）

お手本の線の作り方：

| 候補 | やり方 | 結果 |
|---|---|---|
| A | 曲ファイルをそのまま読み込み、アプリの中で高さを調べる | **予備として入れる**。手間はいちばん少ないが、伴奏で線が乱れる |
| B | パソコンの無料ソフトで「歌声だけ」のファイルを作り、iPhone の「ファイル」に入れて読み込む | **えらんだ（持ち主）**。見やすい線になる見込み |
| C | iPhone のアプリの中で歌声を分ける | えらばない。重すぎる |

## 7. 段6の画面

### 7-1. 曲の一覧
- 「わたしの 曲」の一覧。曲ごとに「曲名」と、持っているもの（🎵 曲ファイル・🎤 歌声だけ・▶ YouTube）の印
- 「＋ 曲を 足す」：曲名を入れ、次の3つから足せる（あとから足してもよい）
  1. 曲ファイル（「ファイル」アプリから選ぶ。m4a・mp3 など）
  2. 歌声だけのファイル（同じ曲を、パソコンで分けたもの）
  3. YouTube のアドレス（`https://youtu.be/…` など）
- 曲を消す（ファイルと線も消える）
- 「歌声だけのファイルの作り方」の案内（7-5）

### 7-2. お手本の線を作る（読み込んだとき1回）
- 歌声だけのファイルがあれば、それから作る。無ければ曲ファイルから作り、「伴奏が まざって いるので、線は 目安です」と出す
- 作っている間は進み具合を出す。できた線は保存し、次からはすぐ開ける
- 自分の声の地図（段2）と比べ、**お手本の高い所が地図の上を超える**なら「この 曲は、キーを ○つ 下げると 楽に なりそう です（目安）」と出す

### 7-3. 買った曲で練習（いちばん大事な画面）
```
[曲名]
━━ お手本の線（全体）━━━━━━━━━━━━━  ← 指でなぞって区間を選ぶ
   [A]────────[B]
[▶ 聞く]  [● 歌う]   速さ：1倍 / 0.75倍 / 0.5倍
聞く音：原曲 / 歌声だけ
━━ 区間の拡大：お手本の線（帯）＋自分の線 ━━
いまの 合いぐあい：65%（目安）  前回：52%
```
- **区間を選ぶ**：全体の線の上で A と B を決める。くり返し再生する
- **聞く**：区間をくり返し流す。「歌声だけ」を選ぶと歌手の声だけが聞ける（耳を育てる）。速さは高さを変えずにゆっくりにする
- **歌う**：イヤホンの確認 → 区間の少し前から流し、合わせて歌う。お手本の線を帯にして、その上に自分の線を重ねる
- 歌い終わったら：合いぐあい（目安）、音ごとの「高め／低め／合っていた」、**前回の自分の線**を薄く重ねて表示
- 1オクターブ上・下で合っていても「合っていた」に数える（段4・5と同じ）
- お手本が声の地図を超える所は、帯の色を変えて「無理に のばさない」と出す

### 7-3b. キーを下げて練習（買った曲だけ。持ち主が選んだ b。**段6の完成後に追加する**。それまでは 7-2 の案内だけ）
- 曲の画面に「キー：0」と −／＋ のボタン（目安の範囲：−6〜＋3）。7-2 の案内で「キーを 2つ 下げると 楽」と出たら、「−2 に する」ボタンも出す
- キーを変えると、**流す音（原曲・歌声だけ）の高さ**と、**お手本の線**の両方が同じだけ動く。速さ（1／0.75／0.5倍）とは別に変えられる
- 判定もずらしたお手本の線で行う
- 曲ごとに、最後に使ったキーを覚えておく
- キーを変えた音は少し音質が変わることがある、と小さく書く
- 音の高さを変える仕組みは、ライセンスを確かめたうえで既にある部品を使ってよい（作る人の判断）。クレジットとライセンス表示を `licenses.txt` に足す

### 7-4. YouTube で練習
- 埋め込みのプレーヤーで流す。区間（A〜B）のくり返し、速さ 1／0.75／0.5倍
- 「歌う」では、自分の声の線だけを出す（お手本の線は無い）
  - **ゆれ**：伸ばしている所で、線がまっすぐかを「安定：○○」と目安で出す
  - **前回と重ねる**：同じ区間の前回の自分の線を薄く重ねる
  - **声の地図**：地図の外に出た所に印
- 埋め込みが止められている動画（持ち主の設定で外で再生できない）は、「この 動画は アプリの 中では 流せません」と出す。電波がないときも案内を出す
- 同じ曲に曲ファイルもあれば、「お手本の 線で 練習する」へ行けるボタンを出す

### 7-5. 歌声だけのファイルの作り方（案内の画面）
- パソコン（Windows または Mac）で、無料の歌声分離ソフトを使う手順を、画像なしの短い手順で書く（どのソフトにするかは作る人が調べて決め、ライセンスと配布元を確かめる）
- できたファイルを iCloud Drive に入れ、iPhone の「ファイル」から選ぶ手順
- 「作ったファイルは自分で使うだけにし、人に渡したりネットに上げたりしない」と書く

## 8. 記録
- 練習ごとに、きろくに「段6」として残す（曲名、区間、合いぐあいの目安）
- 曲と区間ごとに、前回の自分の線（高さの数字の並び）を保存する（声そのものは保存しない）
- バックアップには、曲名・YouTube のアドレス・前回の自分の線を入れる。**曲ファイル・歌声だけのファイル・お手本の線は入れない**（大きく、また曲から作ったものなので、スマホの外に出さない）

## 9. 安全・言葉
- 段6の入口に、イヤホンが必要なことと、高い所を無理にくり返さないことを出す
- 合いぐあいは「目安」。お手本の線も「目安」
- 注意の一言（苦しい・痛いときはやめる、声がれが続くときは耳鼻咽喉科）を出す

## 10. Claude が決めたこと（持ち主が読んで直せる）
| # | 決めたこと | 理由 |
|---|---|---|
| D1 | 持ち主はパソコンを持っている前提 | 候補Bを選んだため。違えば A 中心に変える |
| D2 | 段6は段1〜5の続きで、ホームの一覧に「段6 好きな 曲」として足す。おすすめ（きょうのおすすめ）には出さない | 土台の練習を先にしてほしいため |
| D3 | 曲ファイルの再生は、高さを変えずに速さを変えられる方法を使う | ゆっくりにすると音が低くなると、音程の練習にならない |
| D4 | 曲に合わせて歌う間は、スピーカーに切りかえない（イヤホン前提）。聞くだけのときは、これまでどおり下のスピーカーで鳴らす | 歌う間にマイクの設定を切りかえると、判定がくるう |
| D5 | 段6の帯の太さは、段5のレベルの太さを使う | 新しいレベルを増やさないため |
| D6 | 作る順番：①曲ファイル（お手本の線つき）→ ②YouTube。手順書は①と②で分ける | 持ち主のいちばんの望み「目で見て確かめる」が①でかなうため |
| D7 | 区間は「区間を 保存」で名前を付けて残す（1曲に5つまで）。前回の自分の線は、保存した区間ごとに1回分 | 自由に選んだ区間は前回と同じにならないため |
| D8 | 歌声だけのファイルだけでも練習できる。両方あるときは同じ長さの前提で並べ、長さが1秒以上ちがえば「同じ 曲か 確かめて ください」と出す。聞く音・歌うときに流す音は「原曲／歌声だけ」で切りかえ | 分離ソフトの出力は元の曲と同じ長さになるため |
| D9 | 合いぐあいは、お手本の線を「音」（高さがほぼ同じで続く所）に区切って判定する。お手本の声がない所（息つぎ・間奏）は数えない。数字は「目安」 | 段4・5と同じ考え方で、音ごとに「高め／低め」を出せるようにするため |

| D10 | キーの変更（7-3b）は、段6（①買った曲・②YouTube）が完成したあと、別の手順書で足す（持ち主の判断 2026-11-19）。①②の間はキーの案内だけ | 音の高さを変える仕組みは大きいので、先に段6を使えるようにするため |

## 12. 持ち主が決めたこと（2026-11-19）
- `CLAUDE.md` の文を「既存の曲のメロディのデータをアプリに入れて配らない。利用者が持っている曲から、利用者のスマホの中で作るお手本の線はよい」に直した
- キーを下げて練習する機能は **b**（アプリでも曲を低くして練習できる）。ただし買った曲だけ。YouTube は案内だけ（7-3b）。**最初は案内だけで作り、段6の完成後に追加する**

## 11. 作る人にまかせること
- 曲から高さの線を作る方法（重くならない工夫。区切りながら進める・別の仕組みで動かすなど）と、マイクの遅れの合わせ方
- 曲ファイルの保存のしかた（スマホの中の、大きなファイルを置ける場所）
- 区間の選び方の操作（なぞる・ボタン）の細かいところ
- 歌声分離ソフトの選定（無料・Windows と Mac で使える・ライセンスを確かめる）
- YouTube の埋め込みの細かい使い方

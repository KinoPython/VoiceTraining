# カラオケ音程トレーニングアプリ 設計書

- 作成日：2026-11-18
- 状態：持ち主の OK 済み（2026-11-18）
- 置き場所：このリポジトリ（KinoPython/VoiceTraining）

## 1. なぜ作るのか

持ち主はカラオケで音痴なのを直したい。いまの状態は「いちばん下」で、次のとおり。

- 音を聞いて声を出しても、まったく合わない
- スマホのブラウザで声の高さを針で見ると「低い」とは分かる。でも **耳で聞いて高い・低いは分からない**（聞き分ける力もまだない）
- 声を上げようとすると、上がらないか、**極端に上がりすぎる**（細かく調整できない）
- 曲の「正しいメロディ」も、自分では分からない

使うのは持ち主ひとり（個人で使う）。iPhone のブラウザで使う。

## 2. ゴール

| | 中身 |
|---|---|
| 最低ライン | カラオケで、人前で恥ずかしくない程度に歌える |
| 高い目標 | カラオケの採点で高得点をとる |
| 歌いたい曲 | RADWIMPS、優里「ビリミリオン」、ケツメイシ、GReeeeN |

採点は音程のほかにリズム・声の伸ばし方も見るが、大きいのは音程。だから**まず音程の土台**をつくる。

## 3. やらないこと（非ゴール）

- 曲のメロディのデータを、アプリ側で作る・持つこと（まちがいが入るおそれと、著作権の心配があるため）。曲の答え合わせは **カラオケ店の採点機能（音程バー）** を使う
- YouTube などから曲をダウンロードすること（YouTube の規約で禁止。違法にアップされたものと知りながらのダウンロードは、個人で使うだけでも違法）
- サーバー（歌声の抜き出しなど）。必要になったら、あとで考える
- リズム・ビブラート・しゃくりなどの採点。あとの版で考える
- 多くの人に配ること（今は個人用）

## 4. 失敗と言えること（アンチゴール）

ちゃんと動いても、次のようなら失敗とする。

- **むずかしすぎて、最初の数回で心が折れる**（持ち主はいちばん下から始めるので、最初は必ず「できた」が出る難しさにする）
- 責める言葉、「失敗」「不合格」の赤い大きな表示、連続日数のプレッシャー
- 「必ずうまくなる」「音痴が治る」など、効果を言い切る文
- のどに無理をさせる練習（高い声を何度も押し上げる・長時間続ける）
- 録った声がスマホの外に出ていくこと

## 5. 決まっている条件

- **作り方は A**：スマホのブラウザで動く Web アプリ（PWA。ホーム画面に追加できる）。宅トレアプリと同じく Vite で作る（持ち主が選んだ）
- iPhone の Safari で動くこと。マイクを使う（はじめに許可をもらう）
- 電波がなくても、1〜5段の練習は動く
- 声はスマホの中だけで処理する。外に送らない
- 言葉の決まりは宅トレアプリの `CLAUDE.md` と同じ（効果を言い切らない・病気の治療をうたわない・責めない・連続日数のプレッシャーなし・練習の助言には注意事項）。新しいリポジトリにも同じ決まりの `CLAUDE.md` を置く
- 持ち主はプログラミング初心者。コードは短い関数と日本語の「なぜ」コメント

## 6. 作り方の候補（えらんだ理由）

| | 作り方 | 結果 |
|---|---|---|
| **A** | スマホのブラウザで動く Web アプリ | **えらんだ**。無料で作れる、iPhone でそのまま使える、宅トレで慣れた作り方、YouTube の埋め込みも使える。音の遅れは少しあるが練習には困らない見込み |
| B | iPhone 専用アプリ | えらばない。Mac と Xcode が必要で、作るのも直すのも大変。個人用にはおおげさ |
| C | A＋サーバーで曲から歌声を抜き出す | 今はえらばない。費用と手間、抜き出しの精度がまちまち。答え合わせはカラオケ店の採点で足りる。必要になったら足す |

## 7. 練習の階段（全体）

1段ずつ上がる。上の段に進んでも、下の段はいつでもやれる。

| 段 | 名前 | 鍛えるもの | 版 |
|---|---|---|---|
| 1 | 聞き分け | 耳 | 最初の版 |
| 2 | 声の地図 | 自分の声の幅を知る | 最初の版 |
| 3 | すべらせて止める | のどの微調整（行きすぎを直す） | 最初の版 |
| 4 | 1音合わせ | 耳と声をつなぐ | 最初の版 |
| 5 | 短いメロディ | 音から音へ動く | 最初の版 |
| 6 | 曲で練習（YouTube） | 本番の曲 | 次の版 |

### 段1 聞き分け

- 2つの音を順に鳴らし、「2つ目は 高い？ 低い？」を2つのボタンで答える
- はじめは差をとても大きくする（目安：7半音＝ドとソくらい）。当たり続けたら差を縮め、外れたら少し広げる（階段式。目安：2回続けて当たったら縮める、1回外れたら広げる）。いちばん小さい差は1半音
- 答えたあと、2つの音を**もう一度ゆっくり**聞ける。高いほうの音に印をつけ、見ながら聞き直せる
- 1回は短く（目安：20問）。終わりに「いま聞き分けられる差」を、ピアノの鍵盤の絵で見せる（例：「ドとミの差なら分かる」）
- 音は、やわらかい合成音（Web Audio）。鳴らす高さは、段2で測った「楽な高さ」のまわり（まだ測っていなければ、男女どちらでもとどく真ん中あたり）

### 段2 声の地図

- 「いちばん楽な声で『んー』」→ その高さを「楽な高さ」として保存
- 楽な高さから、ゆっくり下げて／上げて「苦しくない所まで」→ 出せる幅を保存
- **苦しくなる手前で止める**と画面に書く。無理に高い所を測らない
- 結果を鍵盤の絵と「ドレミ」で見せる。いつでも測りなおせる
- 段3〜5のお手本の音は、この幅の中だけで鳴らす（はじめは楽な高さの近く）

### 段3 すべらせて止める

- 画面に、横に流れる**線グラフ**（声の高さの動き）と、目標の帯（横の帯）を出す。針ではなく線にする理由：行きすぎた動きが見えるため
- 目標より少し下から「うー」とゆっくり上げて、帯の中で止める。帯の中に一定時間（目安：1秒）いられたら「できた」
- 目標は楽な高さから2半音くらい上から始め、できたら少しずつ離す。下からだけでなく、上から下ろす練習も入れる
- 帯の太さ（許す幅）は、はじめは広く（目安：上下に半音）、できるようになったら細く

### 段4 1音合わせ

- アプリがお手本の音を鳴らす → 少し間をおいて、同じ高さで「んー」または「あー」
- 線グラフと目標の帯で見せる。帯の中に一定時間いられたら「できた」
- 終わったあと、**自分の声とお手本を続けて聞き直せる**（耳を育てるため。声はその場でだけ使い、保存しない）
- 帯の太さは段3と同じく、広い所から始める
- 外れたときは「少し高め」「少し低め」と、どちらへ動かせばよいかだけを出す（責めない）

### 段5 短いメロディ

- アプリが作った**練習用の短いメロディ**（2〜5音。ドレド・ドレミ・ドミソ など）。既存の曲は使わない
- お手本を鳴らす → 同じように歌う。線グラフに、お手本の音の帯を階段状に並べる
- 帯の中にいた時間の割合を、目安の点数として出す（言い切らず「いまの 合いぐあい」）
- 簡単なもの（2音・となりの音）から、少しずつ音を増やす・跳ぶ幅を広げる

### 段6 曲で練習（次の版）

- アプリの中に YouTube の公式プレーヤーを埋め込む（ダウンロードしない）
- 区間ループ（A〜B）、ゆっくり再生（0.5倍・0.75倍）
- 曲を流しながら、自分の声の線を画面に出す。**イヤホンを使う**よう案内する（スピーカーだと曲の音をマイクが拾うため）
- アプリは YouTube の音の中身を読めないので、正しいメロディの線は出せない。答え合わせはカラオケ店の採点で、と案内する
- 歌う順のおすすめ：ケツメイシ（比較的落ち着いた高さの曲が多い）から → RADWIMPS・優里・GReeeeN の高い曲はあとの目標
- カラオケ店で「キー（高さ）を下げる」使い方の案内も入れる（段2の声の幅と合わせて）

## 8. 毎回の流れ（私の案）

- 1回の目安は **10分くらい**。のどを休める日があってもよい
- はじめに準備（ハミング・ゆっくりのサイレンなど、軽いもの1〜2分）
- ホームに「きょうのおすすめ」1つ（いまの段の練習）。ほかの段も選べる
- 段は「合格しないと進めない」ではなく、**次の段をおすすめする**だけ（自分で選んでもよい）

## 9. アドバイス

- 段ごとに、短いコツを出す。例：段3「上げるときは、坂道をそっと登るように」「力むと上がりすぎやすい」
- 体の使い方の基本（姿勢・息・のどの力み）の短い記事を数本。根拠は出典を確かめて書き、言い切らない
- 安全の一言：苦しい・痛いときはやめる、のどの痛みや声がれが続くときは耳鼻咽喉科で相談、アプリは医療・診断の代わりではない

## 10. 記録

- 日ごとに：聞き分けられた差（段1）、声の幅（段2）、できた数・合いぐあい（段3〜5）
- 変化を見るグラフ（例：聞き分けの差が小さくなっていく様子）。下がった日を責めない
- スマホの中だけに保存。バックアップ（ファイルに書き出し・読み込み）は宅トレと同じ考え

## 11. Claude が決めたこと（持ち主が読んで直せる）

| # | 決めたこと | 理由 |

| C1 | **1オクターブずれ**：段4・5は、お手本と同じ音名で1オクターブ上・下でも「できた」に数え、「1つ上（下）の 高さで 合って いました」と一言出す。段3は本当の高さで見る（すべらせて止める練習なので） | 持ち主は上がりすぎやすく、オクターブずれは起きやすい。厳しすぎると「できた」が出ず心が折れる（4章）。カラオケの採点もオクターブ違いを許すことが多いといわれる |

## 12. 作る人にまかせること

- 声の高さを測る方法（例：YIN や McLeod の方式。小さいライブラリを使ってもよい）と、ゆれをならす方法
- 合成音の音色、線グラフの描き方（canvas など）
- 画面の細かい並び・色（宅トレと同じく `:root` の色トークンで決め、明るい／暗い）
- テストの作り方（計算の部分は自動テスト、マイクは録った音のファイルでテスト）
- 数字の目安（問題数・帯の太さ・1秒など）の細かい調整。実機で試して決める

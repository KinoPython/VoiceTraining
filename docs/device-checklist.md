# iPhone 実機の確かめ表

パソコンのテストでは確かめられないことを、iPhone で確かめる表です。
**Safari で開いた場合** と **ホーム画面に追加した場合** の、両方でやります（ちがう動きをすることがあるため）。
できたら ✅、おかしければ ❌ と、気づいたことを右に書きます。

| # | 確かめること | Safari | ホーム画面 | メモ |
|---|---|---|---|---|
| 1 | はじめの画面が出る。「はじめる」でホームへ進める | | | |
| 2 | 段2で「マイクを ひらく」を押すと、マイクの許可の確認が出る | | | |
| 3 | 許可を「許可しない」にしたとき、やさしい案内が出る（責める言葉がない） | | | |
| 4 | 許可しなかった後、設定を直して、もう一度ひらける | | | |
| 5 | イヤホンをつけて、段1・段3・段4の音が聞こえる | | | |
| 6 | スピーカーで、段1・段3・段4の音が聞こえる | | | |
| 7 | **マナーモード（消音）のときも** お手本の音が鳴る | | | |
| 8 | 段3・段5で、声を出してから線グラフが動くまでの **遅れ** が気にならない | | | |
| 9 | **段4 の聞き直し** をイヤホンでやっても、おかしくなく聞こえる | | | |
| 10 | 練習の途中でホームボタン／スワイプでアプリを閉じる → 戻ると「マイクが 止まりました」の案内が出る | | | |

| 12 | 機内モード（電波なし）で、1回開いたあとにもう一度開いても、ホームと段1が使える | | | |
| 13 | **記録の書き出し**：せってい →「記録を ファイルに 書き出す」で、iPhone の「ファイル」に保存できる | | | |
| 14 | 書き出したファイルを、せっていから読み込める | | | |
| 15 | 「ホーム画面に追加」したアイコンが、きれいに出る | | | |
| 16 | マイクを使う段（段2〜5）で、イヤホンなしでもお手本の音が段1と同じくらい聞こえる（Safari とホーム画面のアプリの両方） | | | |
| 17 | **段6**：曲を足すとき、iPhone の「ファイル」から **m4a** を選べる | | | |
| 18 | **段6**：6分くらいの曲でお手本の線が作れる（かかった時間を メモ。進み具合の％が動き、画面が固まらない） | | | |
| 19 | **段6**：速さ 0.5倍にしても、曲の **高さが変わらない**（低い声にならない） | | | |
| 20 | **段6**：イヤホンで曲を聞きながら歌うと、線グラフに自分の声の線が出る | | | |
| 21 | **段6**：マイクの遅れ。自分の線が、お手本の帯より **右にずれていない** か（ずれるなら `CONFIG.stage6.latencyMs` を直す） | | | |
| 22 | **段6**：「聞く」（歌わずに聞くだけ）は、スピーカーで **大きく** 聞こえる | | | |
| 23 | **段6**：イヤホンの確認で最初の「つけた」を押すと、**ちゃんと曲が流れ始める**（マイクの許可の後でも再生が始まる） | | | |
| 24 | **段6**：区間の始まりの位置から正しく流れる（曲を読み込む前に再生位置を決めても、iPhone で区間の頭から始まる） | | | |
| 25 | **段6**：「歌声だけの ファイルの 作り方」画面の出典の Apple のページ（サポートの URL）が開けて、書いてある手順と合っている | | | |
| 26 | **段6**：同じ画面の UVR の手順が、いま配られている UVR の最新版の画面と合っている | | | |
| 27 | **段6**：機内モード（電波なし）で、足した曲の「聞く」「歌う」が流れる（曲のファイルはスマホの中から読む） | | | |
| 28 | **段6**：AirPods など **Bluetooth のイヤホン** と **線のあるイヤホン** で、自分の線と帯のずれをくらべる（Bluetooth は遅れが大きいことがある。ずれ方をメモ） | | | |

| 30 | **段6**：**VBR の mp3**（長さが一定でない形）で、区間の始まりの位置から正しく流れる（数秒ずれていないか。ずれるなら m4a で試す） | | | |
